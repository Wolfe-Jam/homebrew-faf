# homebrew-faf

Homebrew tap for the FAF ecosystem.

## Install

```bash
brew tap wolfe-jam/faf
brew install wolfe-jam/faf/faf-cli
```

## Formulas

| Formula | Description | Install |
|---------|-------------|---------|
| `faf-cli` | CLI for .faf — init, score, bi-sync, export | `brew install wolfe-jam/faf/faf-cli` |
| `rust-faf-cli` | FAF Compiler — Rust-native, pre-built binary | `brew install wolfe-jam/faf/rust-faf-cli` |
| `claude-faf-mcp` | MCP server for Claude — 33 FAF tools | `brew install wolfe-jam/faf/claude-faf-mcp` |
| `faf-mcp` | Universal MCP server — Cursor, Windsurf, VS Code | `brew install wolfe-jam/faf/faf-mcp` |
| `grok-faf-mcp` | MCP server for xAI Grok | `brew install wolfe-jam/faf/grok-faf-mcp` |
| `wjttc` | Championship-grade test certification for MCP servers | `brew install wolfe-jam/faf/wjttc` |
| `faf-taf-git` | Git-native test receipt printer (.taf) | `brew install wolfe-jam/faf/faf-taf-git` |
| `rust-faf-mcp` | Rust MCP server for FAF — 5 tools, pre-built binary | `brew install wolfe-jam/faf/rust-faf-mcp` |

## One-liner (no tap needed)

```bash
brew install wolfe-jam/faf/faf-cli
```

## Updates

Formulas auto-update via GitHub Actions when new versions are released. Run `brew upgrade` to get the latest.

If `homebrew-faf` has been useful, consider starring the repo — it helps others find it.
